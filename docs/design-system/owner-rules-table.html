Owner rules: decision table

Decision 2 of the methodology brief. For each row: accept, change or reject the proposed rule, check and precedence. Test fails npm test; lint fails the design gate; review item blocks page approval. Proposed extra rules OR-17 to OR-19 after this table: minimal but sufficient with no repeated words; visual salience (a small chip like 2h turns red); never hide important information that can be shown.
